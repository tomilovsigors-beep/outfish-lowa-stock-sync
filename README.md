# outfish-lowa-stock-sync

Separate LOWA supplier → Shopify inventory reconciliation service. It intentionally does **not** share code or deployment with the existing 220 feed.

## Safety model

- Writes only to `Cēcu 18, (Lowa)` (`gid://shopify/Location/107817075026`).
- Never writes Fjord or Veikals.
- Supplier quantities are interpreted as physical stock and compared with Shopify **on_hand**.
- `*` Lithuanian rows are summed with the matching Latvia model/color/width/size.
- `W` is a separate width.
- Supplier total/formula cells are ignored completely; only per-size cells are used.
- Missing Shopify variants are logged and skipped; nothing is auto-created.
- Missing LOWA inventory levels are logged and skipped; nothing is auto-activated.
- Explicit skip rules are in `config/skip_rules.json`.
- Live writes use `inventorySetQuantities(name: "on_hand")` with `changeFromQuantity` CAS protection.
- Live sync is disabled by default and additionally requires a secret header and a reviewed immutable inventory-item map.

## Endpoints

- `GET /health` — no Shopify mutation.
- `GET /dry-run` — fetch supplier XLSX, read Shopify, return proposed changes/skips.
- `POST /sync` — blocked unless all safety locks are enabled.

## Required environment variables

- `SHOPIFY_ACCESS_TOKEN` — custom app Admin API token with `read_inventory`, `read_locations`, `read_products`, `write_inventory`.
- `SUPPLIER_XLSX_URL` — direct HTTPS URL returning the supplier XLSX bytes.
- `SHOPIFY_STORE_DOMAIN=153ac6-2.myshopify.com`
- `SHOPIFY_API_VERSION=2026-07`
- `LOWA_LOCATION_ID=gid://shopify/Location/107817075026`
- `VEIKALS_LOCATION_ID=gid://shopify/Location/84891861330`
- `FJORD_LOCATION_ID=gid://shopify/Location/107805770066`
- `ALLOW_LIVE_SYNC=false` initially.
- `SYNC_SECRET` generated by Render.

## First deployment procedure

1. Deploy with `ALLOW_LIVE_SYNC=false`.
2. Verify `/health`.
3. Run `/dry-run` and save JSON.
4. Review every `update`, `skip_missing_variant`, `skip_lowa_inactive`, and `unmapped_product` row.
5. Build candidate immutable IDs: `python tools/build_locked_map.py dry-run.json > config/locked_inventory_map.candidate.json`.
6. Review the candidate file against Shopify, then commit it as `config/locked_inventory_map.json`.
7. Run `/dry-run` again after deployment. No write yet.
8. Only after explicit approval set `ALLOW_LIVE_SYNC=true` and call `/sync` with `X-Sync-Secret`.
9. Immediately run another `/dry-run` to verify post-write state.

## Important

The initial `locked_inventory_map.json` is deliberately empty, so even if somebody accidentally turns on `ALLOW_LIVE_SYNC`, the service refuses to write mapped inventory until the immutable IDs have been reviewed and locked.
